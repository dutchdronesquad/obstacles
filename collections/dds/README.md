# DDS contract example

This collection demonstrates the version 1 manifest using original diagnostic SVG panels with top-edge arrows and panel names. It contains no club logo or approved club artwork. `status: example` keeps it out of public discovery and uploads while exercising the same validator as MultiGP.

The sources are in `source/`; lossless WebP counterparts are in `textures/`. The example targets `gate-standard-v1`. See the [collection contract](../../docs/collection-contract.md) for slot orientation, rights and publication rules. Reusable design templates and the visually accepted DDS pilot are tracked in obstacles #2; do not mark this example published before that work is reviewed.
